### 运行环境

| 项 | 要求 |
|----|------|
| JDK | 21（`D:\dev-tools\java`） |
| Maven | 3.9.16（`D:\dev-tools\maven`） |
| Node | 已安装 npm |
| 本地仓库 | **D 盘**：`D:\dev-tools\maven-repository`（见第三节注意事项） |

### 0. 终端中文设置（必须，每次打开新终端先执行）

PowerShell 5 默认输出编码非 UTF-8，Maven / Java 日志里的中文会显示为乱码（如 `�ܾ����ʡ�`），导致无法定位报错。**每次执行编译 / 启动 / 日志查看命令前，必须先执行：**

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
```

> 该设置只对当前终端会话生效，新开终端需重新执行。为省事，可在 PowerShell `$PROFILE` 中追加该行实现永久生效。

## 二、后端编译与启动

工作目录统一从后端根目录开始：

```powershell
cd D:\ThalX-smart-student-affairs\notice-module\smart-student-affairs-backend
```

### 2.1 首次 / 修改代码后的编译（install）

> ⚠️ **关键**：只 `mvn compile` 不会让改动生效！`spring-boot:run` 是从本地仓库加载依赖模块的 jar，
> 必须 `mvn install` 把修改后的模块装进仓库，否则跑的是旧代码。

```powershell
# 先设置终端编码（必须）
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8

# 仅编译（快速验证语法）
mvn -o compile -pl smart-student-affairs-notice -am -q

# 编译 + 安装到本地仓库（改代码后必须执行；-o 离线避免沙箱拦截写元数据）
mvn -o install -pl smart-student-affairs-notice -am -DskipTests -q
```

- **必须带 `-am`**：同时构建依赖模块，否则本地仓库缺依赖 jar 会报「找不到符号」
- 需要全量安装（后端所有模块都改了）时：`mvn -o install -DskipTests`
- **编译/安装建议加 `-o` 离线**：在线模式会刷新插件元数据（写 `maven-metadata-central.xml`），被 TRAE 沙箱拦截报「拒绝访问」（见第六节）

### 2.2 启动后端

```powershell
# 先设置终端编码（必须）
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8

# 正常启动（必须带 -o 离线模式 + 不带 -am，见 3.1 沙箱说明）
mvn -o spring-boot:run -pl yudao-server
```

> ⚠️ 启动命令**不要带 `-am`**：离线模式下 spring-boot 插件前缀元数据未缓存时会报
> `No plugin found for prefix 'spring-boot'`。依赖模块已通过 `mvn install` 装入本地仓库，
> 单模块启动即可。

- 启动成功标志：日志出现 `Started YudaoServerApplication`，或端口 48080 开始监听
- 启动约需 30~60 秒

### 2.3 验证后端接口

```powershell
# 后端可达性检查（未登录返回 401 属正常）
Invoke-WebRequest -Uri "http://localhost:48080/admin-api/system/dict-data/simple-list" -TimeoutSec 10 -UseBasicParsing
```

## 三、PC 管理端启动

工作目录：

```powershell
cd D:\ThalX-smart-student-affairs\notice-module\smart-student-affairs-admin-frontend
```

### 3.1 安装依赖（一次性）

```powershell
npm install
```

> 项目用 **npm**，不要用 pnpm（pnpm 会触发依赖库沙箱限制报错 `unable to open database file`）。

### 3.2 启动开发服务

```powershell
# ✅ 本地联调用这个（加载 .env.local，API 指向本地后端 48080）
npm run dev
```

> ⚠️ **不要用 `npm run dev-server`**：它加载 `.env.dev`，`VITE_BASE_URL` 指向远程域名
> `http://api-dashboard.yudao.iocoder.cn`，会导致所有请求 `net::ERR_FAILED`。

启动成功输出：`VITE ready ... http://localhost:80/`

- `.env.local` 已配置 `VITE_BASE_URL=http://localhost:48080`、验证码关闭（用 admin/admin123 登录）
- 修改前端代码后 **Vite 会自动热更新（HMR）**，无需手动重启

### 3.3 前端类型检查（编译验证）

```powershell
# 只检查 notice 模块（tsconfig.notice.json）
npm run ts:check:notice

# 检查是否有 notice 相关错误（其他模块有既有错误，忽略）
npm run ts:check:notice 2>&1 | Select-String -Pattern 'notice'
```

## 四、教师 App 端（uni-app）启动

工作目录：

```powershell
cd D:\ThalX-smart-student-affairs\notice-module\smart-student-affairs-frontend
```

### 4.1 安装依赖（一次性）

```powershell
npm install --legacy-peer-deps
```

> 必须 `--legacy-peer-deps`：`@dcloudio/uni-app` 与 vue 存在 peer 依赖冲突，不加会 ERESOLVE 失败。
> `package.json` 的脚本已自带 `--openssl-legacy-provider`。

### 4.2 启动 H5 开发服务

```powershell
npm run dev:h5
```

- 启动成功输出：`App running at: http://localhost:9090/`
- 编译成功标志：`Compiled with N warnings`（警告不影响运行；项目存在其他模块既有警告，忽略）

### 4.3 启动微信小程序开发（可选）

```powershell
npm run dev:mp-weixin
```

- 产物输出到 `dist/dev/mp-weixin`，用微信开发者工具导入该目录运行
- 正式构建：`npm run build:h5` / `npm run build:mp-weixin`

### 4.4 App 端接口地址

- `config.js` 已配置 `baseUrl: 'http://127.0.0.1:48080'`（本地后端）
- 切换环境改 `config.js` 中 baseUrl 注释行即可

## 五、修改代码后的「重新编译 + 重启」标准流程

### 5.1 后端改了代码

```powershell
cd D:\ThalX-smart-student-affairs\notice-module\smart-student-affairs-backend

# 0. 先设置终端编码（必须）
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8

# 1. 停止正在运行的后端（Ctrl+C，或终止 spring-boot:run 进程）

# 2. 编译并安装到本地仓库（-o 离线）
mvn -o install -pl smart-student-affairs-notice -am -DskipTests -q

# 3. 重新启动（不带 -am）
mvn -o spring-boot:run -pl yudao-server
```

> 典型症状：改了 Controller/Service 但重启后仍是旧行为（如删除接口仍报「request body 缺失」），
> 就是漏了 `mvn install`。

### 5.2 前端改了代码

- **PC 管理端**：Vite HMR 自动生效，刷新浏览器即可；新增依赖时才需要 `npm install` 后重启
- **App 端**：`npm run dev:h5` 有热更新；结构性大改可重启 `npm run dev:h5`

### 5.3 数据库表结构/SQL 变更

- 通知模块的建表与菜单 seed 脚本在 `smart-student-affairs-notice/src/main/resources/sql/mysql/`（`ssa_notice_*.sql`）
- 团队通常已执行，本地如遇表缺失，用 Navicat 手动执行对应脚本

## 六、⚠️ 环境注意事项（踩坑记录）

| 问题 | 原因 | 解决 |
|------|------|------|
| `mvn spring-boot:run` 报 `BUILD FAILURE` + `TRAE Sandbox Error: hit restricted` | TRAE 沙箱禁止 Maven 往 D 盘仓库写 `resolver-status.properties`（快照检查跟踪文件） | 启动带 `-o`（离线）；治本：**TRAE 设置 → 会话 → 自定义沙箱配置** 放行 `D:\dev-tools\maven-repository` |
| `mvn -o spring-boot:run -pl yudao-server -am` 报 `No plugin found for prefix 'spring-boot'` | 离线模式 + 带 `-am` 时 spring-boot 插件前缀元数据未缓存 | 启动**不带 `-am`**：`mvn -o spring-boot:run -pl yudao-server`（依赖 jar 已通过 `mvn install` 装入本地仓库） |
| `mvn install` 报 `拒绝访问`（`maven-metadata-central.xml.tmp`） | 在线模式刷新插件元数据被沙箱拦截 | install/compile 加 `-o` 离线执行 |
| 后端改动不生效 | 只 compile 未 install，`spring-boot:run` 从仓库加载旧 jar | `mvn install -pl smart-student-affairs-notice -am -DskipTests` 后再启动 |
| PC 端请求 `net::ERR_FAILED api-dashboard.yudao.iocoder.cn` | 用了 `npm run dev-server`（加载 `.env.dev` 远程地址） | 改用 `npm run dev`（加载 `.env.local` 本地地址） |
| 后端日志刷 `logs/yudao-server.log 拒绝访问` | logback 写 `C:\Users\16637\logs` 权限不足 | 不影响运行，可忽略；根治需改日志路径或目录权限 |
| 收件人候选只显示教师 | 业务规则：**收件人只能是教师**，候选/提交均按 `teacher` 角色过滤（学生不可选） | 这是预期行为，不要放开 student |
| 编译报「找不到符号 类 Valid」 | 清理 `@RequestBody` 相关 import 时误删了 `jakarta.validation.Valid` | 恢复 `import jakarta.validation.Valid;`（create/update 等接口仍在使用） |
| Maven 一直联网下载 SNAPSHOT | SNAPSHOT 机制每次检查更新 | 本地依赖已装齐后加 `-o` 离线；或先 `mvn install` 装进本地仓库 |
