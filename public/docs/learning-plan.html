团队 AI+IT 学习规划 · 正式版

软件开发技术栈（≤200h）→ AI 工程化进阶（不限时）

⚡ 核心约束：阶段 1-8 总学时 ≤ 200 小时
🔗 学习路径逻辑总览

本规划按照 “语言能力 → 数据持久化 → 业务框架 → 前端交互 → 跨端扩展 → 交付运维 → 全局整合” 的螺旋上升路径设计。 每个阶段既是对上一阶段的实践验证，又是下一阶段的必要前置。 各阶段之间的衔接说明阐释了知识依赖关系，确保学习过程平滑递进，避免跳跃。

🎯 最终目标： 从具备独立全栈开发能力，到能够运用 AI 工程化手段驱动产品持续迭代，形成完整的技术与工程化闭环。
📌 一、核心原则
1.1 小项目精简，快速进入实战

阶段性完成 2～3 个小型项目，掌握核心开发流程后直接参与真实商业项目。减少纯理论学习时间，在实战中加速成长。

1.2 技术栈学习阶段严格控制 AI 介入

在阶段 1-8 中，AI 仅作为辅助学习工具（答疑、解释概念、提示方向），不得进入“接管”级别。所有代码需手动编写，所有异常需亲手排查，以建立扎实的工程基础。

✅ 实施方式：AI 充当 7×24 小时答疑助教，但核心技能必须通过手动编码和调试内化。

1.3 Redis 学习定位

Redis 学习目标为 “理解用途、掌握基本用法、熟悉常见问题及排查方向”，不深入底层原理或源码分析。

1.4 芋道（Yudao）框架的技术底色

🔹 芋道框架基于阿里巴巴技术栈构建，整合了 Spring Cloud Alibaba、Nacos、Sentinel、Dubbo、RocketMQ 等阿里系核心组件，编码规范遵循《阿里巴巴 Java 开发手册》。学习芋道即学习国内头部互联网企业的开发范式，有助于团队对接行业标准。

🛠️ 三、软件开发技术栈学习（阶段 1-8）≤ 200h
⚠️ 本阶段 AI 严格限定为 “辅助学习”，所有代码手写，异常亲手排查。
阶段 1：Java 核心速通（12h）
衔接说明： Java 是后续所有后端框架的语法基石。本阶段聚焦 OOP、集合、IO 和并发基础，为 Spring Boot 的依赖注入、AOP 等特性提供前置认知。小项目①将语法知识落地为可运行的工具，培养编码手感。
模块学时核心内容AI 辅助方式
语言基础 + OOP4h类、接口、抽象类、继承、多态、枚举、泛型AI 解释语法差异
集合框架 + 异常3hArrayList/LinkedList、HashMap、HashSet、自定义异常AI 分析集合选型
IO + 并发入门3hNIO、线程池、Future、CompletableFutureAI 解释并发概念
小项目①2h命令行「待办事项管理工具」AI 辅助 Code Review
📚 推荐： JavaGuide (GitHub) JavaGuide 官网
阶段 2：数据库 + Maven（12h）
衔接说明： 业务系统的核心在于数据。本阶段从 SQL 和表设计切入，同时掌握 Maven 项目构建，为后续集成 Spring Boot 和芋道框架提供“数据底座”与“构建工具”支撑。小项目②直接设计电商数据库，即时应用。
模块学时核心内容AI 辅助方式
Maven 实战2hpom.xml 继承/聚合、依赖冲突AI 解释依赖传递
MySQL 基础与进阶7hDDL/DML、JOIN、EXPLAIN、索引、事务隔离AI 辅助分析执行计划
表设计实战2h范式、主外键设计AI 辅助 ER 图校验
小项目②1h「商品管理系统」数据库 + 5 条核心查询AI 审核索引设计
📚 推荐： mysql-learning (GitHub)
阶段 3：Spring Boot + 芋道后端架构（40h）
衔接说明： 具备 Java 和数据库基础后，自然进入业务框架层。Spring Boot 简化了企业级开发，芋道在此基础上提供 RBAC、多租户、代码生成等成熟方案。本阶段将前两阶段知识融合为可运行的后端服务，小项目③直接产出模块化功能，为前端提供 API 支撑。
🔸 芋道技术栈核心： Spring Boot + Spring Cloud Alibaba + Nacos + Sentinel + MyBatis-Plus + Redis + RocketMQ（可选）。
模块学时核心内容AI 辅助方式
Spring Boot 核心7h自动配置、Bean 生命周期、AOP、事务AI 解释自动配置机制
芋道后端项目结构5h分层、代码生成器、模块划分AI 辅助理解分层
RBAC + 数据权限 + MyBatis-Plus9h权限注解、条件构造器、分页AI 辅助生成模板代码
小项目③7h「客户管理模块」（权限+日志+导入导出）AI 辅助接口设计
芋道高阶能力7h多租户、定时任务、文件上传、工作流AI 辅助排查配置问题
后端代码重构5h统一异常处理、全局响应封装AI 辅助识别坏味道
📚 推荐： yudao-cloud (GitHub) yudao-cloud (Gitee) 芋道云快速启动 芋道云视频教程 在线演示
阶段 4：Redis 快速上手（5h）
衔接说明： 后端服务在高并发场景下依赖缓存加速。Redis 作为最常用的缓存中间件，与芋道框架无缝集成。本阶段安排在核心后端之后，既能理解缓存的价值，又不会过早分散精力。学完后即可在芋道中配置和使用 Redis。
模块学时核心内容AI 辅助方式
概念与场景1.5h缓存/会话/分布式锁、五大数据结构AI 解释场景选型
芋道集成与调用2hRedisTemplate、@CacheableAI 生成 Key 设计参考
常见问题与排错1.5h超时、穿透/击穿/雪崩、慢日志AI 辅助排查
阶段 5：前端基础 + 芋道前端架构（35h）
衔接说明： 后端 API 就绪后，需要前端才能呈现完整产品。本阶段从 HTML/CSS/JS 出发，直指 Vue3 + TypeScript，并深入芋道前端（Vite + Ant Design Vue）。这与后端学习形成“前后对称”，使团队具备全栈视野。小项目④开发数据仪表盘，与后端模块联调，打通前后端闭环。
模块学时核心内容AI 辅助方式
HTML5 + CSS35h语义化、Flex/Grid、响应式AI 解释布局特性
JavaScript ES6+5h箭头函数、Promise/async、闭包、模块化AI 辅助理解异步
Vue3 组合式 API9h响应式、生命周期、watch、自定义 HooksAI 生成组合函数参考
TypeScript 进阶5h类型守卫、泛型约束、工具类型AI 补全类型定义
芋道前端架构6hVite、Ant Design Vue、Axios、路由权限AI 排查跨域鉴权
小项目④5h「数据监控仪表盘」（ECharts + 轮询）AI 辅助性能优化
阶段 6：UniApp 跨端开发（12h）
衔接说明： 移动端是互联网产品的必备渠道。UniApp 基于 Vue 语法，与芋道前端同源，可复用大量组件逻辑。本阶段将前端能力延伸至小程序/H5/App，小项目⑤基于芋道商城模板，直接实践多端适配，为产品全平台覆盖打下基础。
模块学时核心内容AI 辅助方式

核心 API 与组件5huni.request、路由、存储、表单/地图AI 生成交互参考
小项目⑤3h「积分签到」活动页面（基于芋道模板）AI 解决小程序兼容
打包与调试1.5h真机调试、H5/App 打包AI 排查签名权限
阶段 7：部署与测试（25h）
衔接说明： 产品开发完成只是起点，交付上线的能力同样关键。本阶段涵盖 Linux、Docker、Nginx、JUnit 和 Postman，将前面的代码成果部署到真实服务器，并通过自动化测试保证质量。小项目⑥为已开发的用户模块编写单元测试和接口测试，强化质量意识。

阶段 8：全栈整合与代码质量复盘（15h）
衔接说明： 前七个阶段分别构建了不同的能力模块，本阶段承担“总装”角色。从全局视角梳理全链路请求，并关注安全、性能、代码规范等非功能性需求。团队互审前三个小项目，形成统一编码规范。此阶段完成后，团队具备完整的全栈交付能力，可立即进入真实项目开发。

✅ 里程碑： 完成阶段 1-8 后，全栈能力达成。总用时约 156 小时（≤200h），剩余时间可巩固或直接参与真实项目。
