# AI+IT 业务线

## 我们做什么

AI+IT 是社团的核心技术业务线,面向想要系统掌握"编程 + AI"能力的同学,提供从零到一的完整学习路径。我们以 **200 小时内完成全栈入门** 为目标,用项目驱动学习,让每个成员都能独立产出可展示的成果。

## 学习路径概览

| 阶段 | 内容 | 目标学时 |
|------|------|----------|
| 1-2 | Java 核心 + 数据库 + Maven | 24h |
| 3 | Spring Boot + 芋道后端架构 | 40h |
| 4-5 | Redis + 前端基础 + 芋道前端架构 | 40h |
| 6-8 | UniApp 跨端 + 部署测试 + 全栈整合复盘 | 52h |
| 9-13 | AI 工程化进阶(DSPy / LangGraph / Harness) | 不限时 |

> 完整版见 [学习规划 · 正式版](/docs/learning-plan.html)

## 你能获得

- 一套完整的全栈开发能力(前端 / 后端 / 部署)
- AI 工程化的进阶视野(Agent、Harness、自动化)
- 社团内部实战项目经历与作品集
